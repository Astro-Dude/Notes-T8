1Terminal vs Shell vs Linux

  • Terminal = window u type in · Shell = reads & runs ur cmds (bash, zsh) · Linux = an OS
  • Linux is an OS, Bash is a shell → not the same thing!
  • mac: default shell = zsh (bash script.sh still works). mac is Unix-like, NOT Linux
  • check: uname -a · echo "$SHELL" · bash --version · whoami

2Paths & folders

/ root (top of all)

~ my home folder

. here · .. parent

/etc config

/var logs, cache

/tmp temp stuff

/opt extra s/w

/usr tools, libs

home: /Users/u (mac)

  • Absolute path starts with / (full address) · Relative = from where u r now (pwd)
  • ls -la (shows hidden too) · cd .. · cd ~ · cd - (back to last dir) · mkdir -p a/b/c (makes parents too) · touch f.txt

3Files & text cmds

  • cat print · less scroll (q = quit) · head -n 20 first 20 · tail -n 20 last 20 · tail -f app.log = live logs
  • cp a b · cp -R dir1 dir2 · mv old new (move = rename) · rm f · rm -r dir · rmdir d (empty dir only)
  • rm skips Trash → gone forever. check the path before rm -r!
  • grep "ERROR" app.log · -i ignore case · -n line no.
  • find . -name "*.txt" · find . -type f (files only) · wc -l f count lines · file f what type

4Redirection & Pipes

streams: 0 = stdin (input) · 1 = stdout (output) · 2 = stderr (errors)

>output → file (overwrites!)
>>output → file (appends at end)
<take input from file · eg wc -l < notes.txt
2> · 2>>errors → file (overwrite · append) · 2>/dev/null = bin them
>out 2>erroutput & errors in diff files
>out 2>&1both in same file (2>&1 comes AFTER)
a | bstdout of a → stdin of b
tee fshow on screen + save to file (-a append)
  • pipe carries only stdout, not stderr. want both → cmd 2>&1 | grep x
  • eg ps aux | grep Terminal | wc -l · tip: grep X f > cat f | grep X

5Users & Permissions

-type rwxuser(u) r-xgroup(g) r--others(o) ← ls -l

r=4 w=2 x=1 → 7=rwx · 6=rw- · 5=r-x · 4=r--

755 = rwx r-x r-x (scripts) · 644 = rw- r-- r-- (normal files)

chmod u+x s.sh · chmod g-w f · chmod o+r f · chmod u=rw,go=r f (= 644)

on a fileon a dir
rread contentlist names inside
wedit contentcreate/delete/rename inside (+x)
xrun itenter / cd into it (not "run")

chown user:group f new owner · sudo cmd = run as admin · id = me + groups

6Processes & Services

  • process = a running program, has a PID. ps aux all · top live (q = quit)
  • sleep 60 & runs in bg · jobs list · fg %1 job 1 to front · Ctrl+C stop
  • kill PID = SIGTERM "please stop" · kill -9 PID = SIGKILL force (last option)
  • service = bg process the OS keeps running. process ≠ service
  • Linux: systemctl status|start|stop|restart|enable X (enable = start on boot)
  • mac uses launchd → launchctl list. no systemctl on mac!

7Script basics & variables

#!/bin/bash          ← shebang = which program runs it
name="Astro"         ✓ NO spaces around =
name = "Astro"       ✗ bash thinks name is a cmd
echo "Hi $name"      → Hi Astro   (double = expands)
echo 'Hi $name'      → Hi $name   (single = as it is)
echo "${name}Dude"   → AstroDude  ({} = where name ends)
dir="$(pwd)"         → cmd output saved in var
sum=$((5 + 3))       → 8  (math)
  • run → bash s.sh OR chmod +x s.sh then ./s.sh
  • vars are strings by default. always quote "$var" (safe with spaces)
★★

8if / else & tests

if [ "$age" -ge 18 ]; then echo "Adult"
elif [ "$age" -gt 0 ]; then echo "Minor"
else echo "Invalid"; fi

⚠ space after [ and before ] → [ "$a" -eq 1 ] ✓ ["$a" -eq 1] ✗

numbers-eq · -ne · -gt · -ge · -lt · -le (not = !)
strings= · != · -z empty · -n not empty
files-e exists · -f file · -d dir · -r read · -w write · -x exec
logic&& and · || or · ! not

[[ -d "$p" && -r "$p" ]] → [[ ]] = bash version, safer for combos

9Loops

for n in Astro Sam Alex; do echo "Hi $n"; done
for i in {1..5}; do echo "$i"; done     → 1 2 3 4 5
c=1; while [ "$c" -le 5 ]; do echo "$c"; c=$((c + 1)); done
  • while → update the var or it loops forever (Ctrl+C to escape)
  • break = exit loop now · continue = skip to next round

10Functions

greet() { echo "Hello, $1"; }
greet "Astro"                 → Hello, Astro
add() { echo "$(($1 + $2))"; }
res=$(add 10 20)              → res = 30
  • defining ≠ running → call it by name. $1 $2 inside fn = fn's own args
  • return = only a status 0–255 (0 = ok). want data back → echo + $(…)
  • local x=5 → x lives only inside the fn

11Script arguments

bash s.sh apple "big mango" →

$0 = s.sh · $1 = apple · $2 = big mango · $# = 2 (count)

"$@" = each arg separate ✓ (use in loops) · "$*" = all joined in 1 string

shift → drops $1, rest move left ($2 becomes $1)

12Exit status & errors

  • 0 = success, non-zero = fail · echo $? = last cmd's status
  • exit 1 ends the script · return 1 ends a fn · errors → stderr: echo "oops" >&2
  • set -u unset var = error · set -e stop on fail (not 100% reliable)
if [ "$#" -ne 1 ]; then
    echo "Usage: bash check.sh DIR" >&2; exit 1
fi

⚠ Exam traps — don't lose marks here

  1. > overwrites, >> appends
  2. pipe = stdout only
  3. dir r = list · dir x = enter
  4. x=5 ✓ · x = 5 ✗
  5. numbers → -eq, not =
  6. while: update var or ∞
  7. return = status, echo = data
  8. "$@" keeps args apart
  9. rm has no undo
  10. check cmd worked before saying "done ✓"

AWho / where am I

  • echo "$SHELL" → which shell I use
  • bash --version → bash version
  • whoami → my username
  • id → my UID, GID & groups
  • pwd → full path of current folder

BMove around & list

  • ls → list files
  • ls -l → long list (perms, owner, size)
  • ls -la → long list + hidden files
  • cd /path/to/folder → go to that folder
  • cd .. → up one folder
  • cd ~ → go home
  • cd - → back to the last folder

CCreate · copy · move · delete

  • mkdir project → new folder
  • mkdir -p project/src/components → makes all parent folders too
  • touch notes.txt → new empty file
  • cp a.txt b.txt → copy a file
  • cp -R src_dir dest_dir → copy a whole folder
  • mv old.txt new.txt → move or rename
  • rm file.txt → delete file ⚠ no Trash
  • rm -r dir → delete folder + everything in it
  • rmdir empty_dir → delete folder (only if empty)

DRead files

  • cat f → print the whole file
  • less f → scroll through it (q = quit)

  • tail f · tail -n 20 f → last 10 · last 20 lines
  • tail -f app.log → follow a live log
  • file f → what type of file it is
  • wc -l f → count lines

ESearch

  • grep "ERROR" app.log → lines that have ERROR
  • grep -i "error" app.log → ignore upper/lower case
  • grep -n "ERROR" app.log → also show line numbers
  • find . -name "*.txt" → find files by name
  • find . -type f → only files (no folders)

FServices

  • systemctl status X → is it running? (Linux)
  • systemctl start|stop|restart X → control it
  • systemctl enable X → auto start on boot
  • launchctl list → mac: list services
  • launchctl print gui/$(id -u) → mac: my user's services
★★

GRedirection & pipes

  • cmd > out.txt → output → file (overwrite)
  • cmd >> out.txt → output → file (append)
  • cmd < in.txt → read input from a file
  • cmd 2> err.txt · cmd 2>> err.txt → errors → file · append
  • cmd > out 2> err → output & errors in 2 files
  • cmd > out 2>&1 → both into the same file
  • cmd 2>/dev/null → hide errors
  • a | b → a's output goes into b
  • cmd | tee f · tee -a f → screen + file · append
  • ps aux | grep "Terminal" | wc -l → eg chain of 3 cmds

HPermissions & users

  • chmod u+x script.sh → owner can run it
  • chmod g-w f → group can't write
  • chmod o+r f → others can read
  • chmod u=rw,go=r f → set exactly (= 644)
  • chmod 755 script.sh → rwx r-x r-x
  • chmod 644 notes.txt → rw- r-- r--
  • chown user:group f → change owner (needs sudo)
  • sudo COMMAND → run as admin

IProcesses & jobs

  • ps · ps aux → my shell's · ALL processes
  • ps aux | grep "name" → find one process
  • top → live view (q = quit)
  • sleep 60 & → run in background
  • jobs → list bg jobs
  • fg %1 → bring job 1 to front
  • kill PID → polite stop (SIGTERM)
  • kill -9 PID → force kill (SIGKILL)
  • Ctrl+C → stop the cmd in front

JBash script toolkit

  • bash script.sh ARG → run a script
  • chmod +x script.sh · ./script.sh ARG → run it directly
  • echo "text" · echo "oops" >&2 → print · print to stderr
  • var=$(cmd) · $((a + b)) → save output · math
  • [ "$a" -eq 1 ] · [[ -d "$p" && -r "$p" ]] → test
  • exit 1 · return 1 → end script · end fn
  • shift · local x=1 → drop $1 · fn-only var
  • set -u · set -e → unset var = error · stop on fail
  • echo $? → last cmd's exit status
  • basename "$dir" · tr -d ' ' → last part of path · delete spaces
  • $0 · $1 · $# · "$@" → script name · 1st arg · count · all args

5Images, tags & Docker Hub

6Networking

  • -p 8080:80 = HOST : CONTAINER (order matters) → localhost:8080 hits port 80 inside
  • EXPOSE = just a note ≠ publish. only -p publishes.
  • same user-defined network → talk by name (Docker DNS) → http://web
  • localhost inside a container = itself, not the other container
docker network create app-net
docker run -d --name web --network app-net nginx
docker run --rm --network app-net busybox nslookup web   ✓ finds it

8Dockerfile + layer cache

FROM node:22-alpine         base image
WORKDIR /app                cd (makes it if missing)
COPY package*.json ./       deps list FIRST
RUN npm ci                  install deps  ← cached ✓ if json same
COPY . .                    code (changes a lot)
ENV NODE_ENV=production     env var
EXPOSE 3000                 just a note
CMD ["node", "server.js"]   default start cmd
  • each line = a cached layer · change a line → it + all below rebuild
  • copy package.json before code → npm ci stays cached
  • ADD = COPY + tar/URLs · ARG = build-time only · USER · LABEL
  • build → docker build -t my-app:v1 . (. = build context)

9CMD vs ENTRYPOINT

  • CMD = default cmd/args → replaced by args after image name
  • ENTRYPOINT = main program (fixed) → change only with --entrypoint
ENTRYPOINT ["python"]
CMD ["app.py"]                       → python app.py
docker run my-image other.py         → python other.py
docker run --entrypoint sh -it my-image

✓ use JSON form ["a", "b"] → app gets stop signals

10.dockerignore & small images

.dockerignore: .git node_modules .env coverage dist → not sent to the build

  • never bake secrets / .env into an image
  • small base (alpine) · multi-stage · non-root USER · pin versions
FROM node:22-alpine AS build                    ← stage 1: builds
WORKDIR /app
COPY . .
RUN npm ci && npm run build
FROM nginx:alpine                               ← stage 2: ships
COPY --from=build /app/dist /usr/share/nginx/html

→ final image has only dist files, no node / npm → tiny image ✓

★★

11Volumes & storage

named volumeDocker manages itDB data · stays ✓
bind mounthost folder ↔ containerdev, live code
container layerinside the containergone on rm ✗

rule: -v NAME:/path = named · -v /host/path:/path = bind

docker volume create app-data      docker volume ls
docker volume inspect app-data     docker volume rm app-data
docker run -d --name db -v app-data:/var/lib/data my-db-image  ← named
docker run --rm -v "$PWD":/app -w /app node:22-alpine npm test ← bind
  • rm container ≠ delete named volume (rm -v = only anonymous ones)
  • bind mount hides files already at that path in the image

2Skip a call → what breaks?

no bind()nothing owns the port → kernel answers SYN with RST → "connection refused" · fast, loud
bind + listen, no accept()kernel finishes the handshake itself, conn waits in queue → client hangs till timeout · looks like an overloaded server
one read() onlyone read ≠ a conversation → loop while ((n = read(…)) > 0)

9fork() server — the child does the talking

while (1) {
  int c = accept(server_fd, NULL, NULL);
  if (fork() == 0) {                    ← child
    while ((n = read(c, buf, sizeof buf)) > 0) write(c, buf, n);
    close(c); return 0;                 ← serve 1 client, exit
  }
  close(c);                             ← parent: drop its copy, loop
}

6Many clients at once

7TLS secures TCP, not HTTP

  • asymmetric crypto to agree a shared secret → symmetric for the data (much faster)
  • certificate binds a key to an identity, CA chain is why u trust it (expires at 3 am…) · pinning = trust only this cert (mobile apps)
  • same TLS protects SSH-like, SMTP, DB connections — anything on a socket

9select() loop, annotated

listen(server_fd, 16);  int clients[FD_SETSIZE]; int n = 0;
while (1) {
  fd_set r; FD_ZERO(&r); FD_SET(server_fd, &r);   ← rebuild EVERY loop
  for (i = 0; i < n; i++) FD_SET(clients[i], &r);
  select(maxfd + 1, &r, NULL, NULL, NULL);     ← NULL = wait forever
  if (FD_ISSET(server_fd, &r)) clients[n++] = accept(server_fd, 0, 0);
  for (i = 0; i < n; i++) if (FD_ISSET(clients[i], &r)) {
    k = read(clients[i], buf, 4096);
    if (k <= 0) { close(clients[i]); clients[i] = clients[--n]; i--; } ← O(1) delete
    else write(clients[i], buf, k);
  }
}

flood it with 1,100 conns → dies at fd 1024 · ulimit -n 65536 does not help (bitmap width is compiled in) · same flood on epoll at 5,000 → nothing happens

8The 4 ideas

  • amortise the setup: pre-fork, pre-thread, FastCGI, pools, servlets → pay once at startup
  • nothing is free per connection: fd + stack + buffer + scheduler entry × 10,000

  • concurrency = throughput × latency → only getting faster reduces it

4How to retry

while True: try call() except Timeout: continue → no cap, no delay, all clients in sync = thundering herd

for attempt in range(max_attempts):          ← cap total damage
    try: return fn()
    except Retryable:
        if attempt == max_attempts - 1: raise
